## 2026-10-26 全项目审查与修复

本轮按现有规格、安全约束及界面契约审查采集、存储、恢复、桌面端、调度、安装发布和旧数据迁移。以下问题使用临时数据目录、故障注入及模拟远端复现；修复保持现有模块结构。

| 问题 | 修复后的行为 |
|---|---|
| 在途任务撤权后无法核账 | 已知 Run 可通过“登记最终账单”查询远端终态，停止剩余内容导入并登记人工核账证据；不读取 Dataset，也不推断零费用。旧 adapter 退役时 UNKNOWN 仍可人工绑定既有 Run 后核账；未核对或仍在运行的 Run 继续阻断。 |
| 降低单次限额误判历史账单超额 | 历史费用按该任务创建时的 reserved_usd 比较；新上限只约束新任务。真正超出历史上限的费用仍阻断。 |
| 旧观测回退当前正文 | 过时内容不替换当前版本；同时间不同正文作为冲突隔离，保留当前正文与审核。 |
| 整批都无法容纳的媒体无限等待 | 超过完整批次容量记为永久 OVERSIZE，继续处理后续文件；仅剩余额度不足时才留待下一批。 |
| 原子写入残留逃过删除清理 | 恢复识别实现自有的 pending、segment、manifest、CURRENT 原子临时文件并隔离；删除流程清理这些残留，失败不得报告完成。 |
| 清理目标路径误删后续合法导出 | 已完成目标从待清理路径中消费；删除后完成凭据写入中断时，重新登记前先持久化消费旧路径。相同路径重新登记的合法导出得以保留，未完成目标继续重试。 |
| 备份缺失最新许可退回旧授权 | 恢复在复制前要求 POLICIES.json 存在并通过归属、结构及字段校验；快照清理同样禁止回退旧许可，创建快照必须成功同步当前许可。 |
| 发布许可撤销后仍显示可发布 | 读取帖子、详情及 CSV 时按当前 redistribute 许可降级展示，保留原审核事件作为历史证据。 |
| 详情窗口保留已撤回正文 | 每次成功复核都更新显示内容；仅保留元数据时移除原正文，拒绝后的迟到回调不能重新显示内容。 |
| 自动计划复用旧配置验收 | 手动验收绑定当前账号、许可上下文、模式、Actor/build 和映射版本；计划任务不能冒充手动验收。配置切换停用计划，每次计划创建再验证账号。 |
| 清理告警漏报或无法消除 | 根据实际清理与外盘同步结果更新告警；失败保持待处理，后续成功清除对应告警。 |

运行结果及尚未覆盖的实机验收边界见 README.md 末尾、docs/TEST_RESULTS.txt 与 docs/release-gates.json。未执行真实付费 Run、远程推送或发布。

兼容性：新增 `CONFLICTING_CONTENT_OBSERVATION` 隔离原因，严格枚举的旧 reader 无法重放此事件，因此最低 reader level 提升为 **11**，安装器拒绝回滚到旧 reader。现有数据直接重放，无需新增迁移模块。
