# M0–M4 实施与验收报告

版本 0.0.4。基于 v0.0.3 继续开发，保持原有回归测试。新增 19 项 M4 测试，当前 **72 + 6 = 78 项通过**；实际输出在 TEST_RESULTS.txt。Linux + Python 3.12.14，Windows/NTFS 尚待实机验收。第三方运行依赖为零。

## 交付

持久化媒体队列与独立提交；权限/范围/到期检查；SFW/R18/UNKNOWN 与 restricted 门禁；HTTPS allowlist、DNS 全地址审查、固定 IP/TLS、重定向重验；流式大小/空间保护、文件签名/MIME/hash 与去重；有限重试、永久失败手动修复；安全预览路径接口及 redistribute 独立许可检查。

总活动目录 50 GiB / 剩余 10 GiB 配额接入提交和媒体块写入；80% 告警。删除包含持久化防复活屏障、完整新链构造与原子切换、历史段清理、共享 Blob 引用处理、可登记的派生文件清理、媒体到期与帖子来源 retain 撤回清理，失败有 pending/异常，无虚假全系统完成。

## 验证

- T02：未知/撤销许可不发媒体请求；队列和预览均重复检查。
- T12：网络故障最多三次尝试；过大/过期链接/MIME错误不回滚帖子；永久失败需 repair。
- T13：UNKNOWN/R18/restricted 阻断；账号 R18 不将明确 SFW 帖子自动升级；无自动预览。
- T15：目录上限及最低空闲边界阻断写入；小量错误元数据使用安全保留。
- T19 子场景：登记旧快照清理、恢复旧 journal 保留独立删除屏障不复活、三处 compaction 中断及媒体清理中断后可恢复。跨磁盘与全新目录恢复待 M6。
- SSRF：协议、主机后缀伪装、端口、userinfo、控制字符、混合公网/内网 DNS 均拒绝。生产连接固定 IP，TLS 用正确 server_hostname。
- 媒体到期只删素材，帖子仍在；保留许可撤回删除帖子历史；共享 Blob 最后一个有效引用消失后才删。

## 具体限制

真实 Actor 与媒体 HTTP 未执行；无 Apify 费用。当前 ScrapeSage 返回结构仍未验证；媒体需要调用方显式提交已审核 URL 与期限，不从不明 Actor 字段自动下载。格式校验不是完整图片/视频解码或病毒检测。R18 人工证据真实性及来源许可由审核人负责。

副本清理只覆盖登记的本地应用文件；未知/变更文件报告未完成，不删除用户未知文件。外部备份在 M6 建立登记和物理磁盘校验后接入，不冒充已清理；未取得完整 G1/G2/G3。删除不是 SSD 安全擦除；删除屏障不可在还原时被旧副本覆盖。
